# sismo

Alias corto de [`@crafter/sismo-cli`](https://www.npmjs.com/package/@crafter/sismo-cli), el paquete canónico de Sismo Abierto.

El alias publicado permanece en `1.0.0`. Para soporte de Colombia usa el paquete canónico `@crafter/sismo-cli@1.1.0`.

```bash
bunx --bun @crafter/sismo-cli latest
bunx --bun @crafter/sismo-cli events --since 7d --json
bunx --bun @crafter/sismo-cli schema events
```

El alias fija una versión del paquete canónico y delega toda la ejecución. No mantiene una implementación separada.

Proyecto comunitario. Fuente de datos: IGP. No es un sistema de alerta ni de predicción.
